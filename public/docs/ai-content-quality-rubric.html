AI-Generated Page Quality Rubric

A shared evaluation framework for assessing whether AI-generated pages meet production quality. Measures how well the AI leverages brand packs, design system components, and page type conventions to produce publishable content.

Scope: AI-generated pages & experiences Version: 1.0 Date: 2026-07-03 Dimensions: 5 Criteria: 16

What This Rubric Evaluates

AI-generated output falls into two categories. The rubric applies to both, with criteria weighted the same but expectations shaped by the type.

Page Types

Structured, content-driven pages with a defined schema and repeatable format.

  • Blog post
  • Product detail page
  • Article / news page
  • Help / knowledge base article
  • Event detail page

Experience Types

Marketing-driven compositions designed around a goal, audience, or campaign.

  • Landing page
  • Campaign page
  • Email template
  • Social media content
  • Banner / hero section

Scoring Levels

Each criterion is scored on a four-point scale. Each level assumes all conditions of the level below are also met.

4 — Excellent

Exceeds expectations. Enhances the brand and could serve as a reference example for future pages.

3 — Good

Ready to publish. Matches the quality of existing hand-crafted pages on the same site.

2 — Fair

Functional with minor issues. Usable after light editorial or design review.

1 — Poor

Requires significant rework. Visual, structural, or content issues that block publication.

Quality Rubric

16 criteria grouped into 5 dimensions. Weights reflect relative importance to overall page quality. A page must meet the pass threshold defined below to be considered "good quality."

Dimension Criterion 4 — Excellent 3 — Good 2 — Fair 1 — Poor
1. Visual / Layout Correctness 25%
Key indicators Pixel-perfect; matches existing pages exactly Clean layout, proper spacing, clear visual hierarchy Slight spacing or alignment inconsistencies Broken layout, misaligned elements, visual hierarchy issues
Visual / Layout Spacing & alignment
  • Spacing is identical to the best existing pages on the site
  • Vertical rhythm creates a polished, magazine-quality feel
  • Spacing follows the design system's scale consistently
  • Even vertical rhythm between sections
  • All elements properly aligned within their containers
  • Spacing is mostly consistent; 1–2 irregular gaps
  • Minor alignment issues that a designer would flag
  • Irregular, inconsistent spacing throughout
  • Overlapping or clipped elements
Visual hierarchy
  • Hierarchy guides the eye through a clear narrative arc with natural transitions
  • Size, weight, and color contrast work together to create unmistakable priority
  • Clear size/weight progression from headings to body text
  • Primary CTA is visually prominent; secondary actions are clearly subordinate
  • Content sections are visually distinct and easy to scan
  • Hierarchy exists but some levels feel too similar in weight
  • CTA visible but doesn't stand out as the primary action
  • All text at similar visual weight; no clear reading order
  • CTA buried, missing, or competing with other elements
Responsive design
  • Layout is polished at every viewport width, not just standard breakpoints
  • Content reflows elegantly; feels intentionally designed for each screen size
  • Page reflows cleanly from desktop to tablet to mobile
  • Images and media scale proportionally
  • No horizontal scroll or content overflow at any size
  • Desktop looks correct; mobile has minor overflow or tight spacing
  • Some elements don't resize well between breakpoints
  • Fixed layout that breaks on smaller screens
  • Content is cut off or inaccessible on mobile
2. Component Composition 25%
Key indicators Innovative yet compliant component arrangements that elevate the design Correct components, proper variants, follows design system guidelines Components work but could be better organized or selected Wrong components for content type, missing required elements
Component Composition Component selection
  • Every component choice is optimal — the best variant for each context, not just a correct one
  • Creative use of existing components to solve novel layout needs without breaking conventions
  • Uses the design system's established components throughout (buttons, cards, heroes, forms, navigation)
  • Correct component variants selected for context (e.g., primary vs. ghost button, compact vs. standard card)
  • Mostly correct components; 1–2 cases where a better component exists in the design system
  • Wrong components for the content type (e.g., a data table used where cards are standard)
  • Inconsistent component choices across the page
Design system compliance
  • 100% design system coverage — no custom or one-off elements
  • Demonstrates mastery of the system's constraints and capabilities
  • All colors, spacing, typography, and border radii from the design system's token set
  • No custom styles that duplicate what a token or component already provides
  • Component configurations (sizes, appearances, states) are all valid
  • Mostly uses design tokens; 1–2 custom values where a token exists
  • Components configured correctly but not optimally
  • Custom colors, spacing, or typography that bypass the design system
  • Components used with invalid configurations
Image & media usage
  • Imagery is contextually perfect — reinforces the message and matches the brand's visual style
  • Media composition (cropping, placement, sizing) feels intentional and editorial
  • Images are relevant to the content and appropriately sized for their containers
  • No placeholder images, broken links, or stock-photo-obvious selections
  • Image style (photography, illustration, iconography) matches the site's visual identity
  • Images display correctly but feel generic or loosely connected to content
  • Sizing is acceptable but not optimized for the layout
  • Missing images, broken placeholders, or visually irrelevant media
  • Images clash with the site's visual style
Interaction & states
  • Hover, focus, active, and disabled states are all polished and consistent
  • Micro-interactions feel natural and enhance usability
  • Buttons, links, and interactive elements have appropriate hover and focus states
  • Form elements show clear validation feedback (error, success)
  • Loading and empty states are handled, not blank
  • Primary interactions work; secondary states (hover, focus) are default or missing
  • Interactive elements with no visible feedback on hover or click
  • Missing error, empty, or loading states
3. Page / Experience Type Fidelity 20%
Key indicators Structure enhances content impact beyond the type's baseline conventions All expected sections present, logical flow, type conventions followed Mostly complete; minor ordering or section issues Missing critical sections, wrong structure for the page type
Type Fidelity Section structure
  • All required sections present and enhanced with contextually smart additions (e.g., related content, social proof, author bio on a blog post)
  • All expected sections for the page type are present (e.g., blog: hero, body, author, tags; landing page: hero, features, testimonials, CTA)
  • Section order follows the type's established convention
  • No empty, stub, or placeholder sections
  • Required sections present; order slightly rearranged
  • One optional section missing or underdeveloped
  • Missing critical sections for the type (e.g., a landing page with no CTA)
  • Placeholder text like "Lorem ipsum" or "[Add content here]"
Type conventions
  • Page feels like a best-in-class example of its type
  • Conventions are followed and then elevated with smart design decisions
  • Page is immediately recognizable as its type (a blog post reads like a blog post, a landing page converts like a landing page)
  • Content zones, grid layouts, and media placements follow type norms
  • Metadata appropriate for the type (date, author, category for blog; hero, CTA, conversion focus for landing page)
  • Generally follows type conventions; one element feels out of place
  • Page doesn't follow the conventions of its declared type
  • A blog post that looks like a landing page, or vice versa
Template fidelity
  • Template structure followed and thoughtfully adapted — content shapes the template, not the other way around
  • Output matches the selected template's layout, proportions, and content zones
  • Content types fill template slots correctly (image where image expected, text where text expected)
  • Overall shape matches the template; minor deviations in proportions or zones
  • Output doesn't match the selected template
  • Completely different layout than what was requested
4. Content Relevance 15%
Key indicators Content exceeds expectations and adds clear value beyond the brief Content serves intended purpose effectively Mostly relevant with minor misaligned sections Content doesn't match page purpose or user needs
Content Relevance Topical accuracy
  • Content demonstrates domain expertise; adds insight beyond what was prompted
  • No generic AI filler — every sentence is specific and purposeful
  • All copy is on-topic and specific to the subject matter
  • No hallucinated facts, fabricated statistics, or invented features
  • Claims are plausible and internally consistent across the page
  • Mostly on-topic; 1–2 vague or generic sentences that could apply to anything
  • Fabricated details or factually incorrect statements
  • Generic filler clearly unrelated to the intended topic
Content depth
  • Content is rich enough to publish without editing
  • Includes supporting evidence, examples, or social proof beyond what was prompted
  • Body sections contain substantive detail, not just headlines
  • Feature or benefit descriptions include supporting context
  • Content length is appropriate for the page type (e.g., 300+ words for blog posts, concise for banners)
  • Content is present but thin; some sections read like outlines rather than finished copy
  • Headline-only content with no supporting detail
  • Significantly under expected length for the page type
Audience & goal fit
  • Content is clearly optimized for the target audience and conversion goal
  • Experience types: messaging drives toward a measurable action
  • Page types: content satisfies the reader's intent completely
  • Tone and complexity match the intended audience
  • Content supports the page's primary goal (inform, convert, engage)
  • CTAs are relevant and clearly tied to the value proposition
  • Broadly appropriate but misses some audience or goal nuances
  • Content written for the wrong audience or purpose
  • No clear connection between content and the page's goal
5. Brand Alignment 15%
Key indicators Strengthens brand identity through excellent execution Follows brand pack guidelines consistently Minor brand guideline deviations Wrong tone, off-brand colors/fonts, messaging conflicts
Brand Alignment Tone & voice
  • Voice is so consistent it enhances brand perception — reads as if written by the brand's best copywriter
  • Tone adapts naturally to context (empathetic for support, energetic for launches) while staying on-brand
  • Copy reflects the brand pack's defined tone keywords and voice rules
  • Voice is consistent throughout the page — no jarring shifts between sections
  • Avoids phrases flagged in the brand pack's "don't use" examples
  • Tone is broadly on-brand but inconsistent between sections
  • Occasional phrasing that doesn't match the brand's style
  • Tone contradicts the brand pack (e.g., stiff and corporate when brand is playful)
  • Generic AI-sounding copy with no distinct brand personality
Visual brand
  • Color, typography, and imagery work together to create a cohesive, premium brand impression
  • The page strengthens the brand's visual identity
  • Colors match the brand pack palette (primary, secondary, accent applied correctly)
  • Typography uses the brand pack's configured heading and body fonts
  • Logo/wordmark present in the correct position and size
  • Imagery style matches the brand's visual identity
  • Primary brand color correct; secondary/accent slightly off
  • Logo present but placement deviates from brand pack
  • Colors unrelated to the brand pack palette
  • Wrong, missing, or distorted logo; off-brand imagery
Brand pack compliance
  • Every brand rule followed and the result actively elevates the brand's market positioning
  • All explicit rules in the brand pack are followed (color usage, logo clear space, messaging guidelines)
  • Content targets only approved channels defined in the brand pack
  • Messaging aligns with the brand's positioning and value proposition
  • Brand pack mostly followed; one non-critical rule missed
  • Brand pack rules ignored or contradicted
  • Messaging conflicts with brand positioning

Pass / Fail Threshold

A generated page is considered "good quality" when all of the following are true:

  • No criterion scores 1 (Poor) — any Poor score is a blocking defect that requires rework before publication.
  • Weighted average ≥ 3.0 — calculated as: ∑(dimension_avg × weight). A page averaging 2.0 (Fair) is functional but not publishable without significant review.
  • Brand pack active — the page has an active brand pack with colors, typography, and tone/voice rules configured.
  • Type requirements met — all mandatory sections for the selected page type or experience type are present and populated.

How to Use This Rubric

Context Method Outcome
Manual review Reviewer scores each of the 16 criteria 1–4 using the descriptors above. Takes 5–10 minutes per page. Scorecard with per-dimension averages and overall weighted score. Pages ≥ 3.0 pass; others get a list of specific criteria to improve.
Automated checks Criteria from dimensions 1–3 (Visual, Component, Type Fidelity) can be partially automated via design system linters, layout validators, and section-completeness checks. Automated gate that flags low-scoring criteria before human review. Reduces manual effort to dimensions 4–5 (Content, Brand).
AI self-evaluation Pass the rubric as context to the AI. After generation, the AI scores its own output and flags any criterion below 3. Self-improvement loop: the AI re-generates sections that scored below 3, surfacing only passing pages to the human reviewer.
A/B comparison Score both a hand-built page and an AI-generated version of the same content. Compare per-criterion deltas. Identifies which quality dimensions the AI excels at vs. struggles with, informing prompt engineering and template design.

Methodology: Analytic rubric design based on Allen & Tanner (2006), "Rubrics: Tools for Making Learning Goals and Evaluation Criteria Explicit for Both Teachers and Learners," CBE—Life Sciences Education, 5(3), 197–203. Criteria informed by design system best practices, brand pack configuration schemas, and page type / experience type content standards.

Maintenance: Review and update this rubric quarterly or when significant changes are made to brand packs, design system components, or page type definitions. Add new criteria only when an existing dimension cannot capture a recurring quality issue.
