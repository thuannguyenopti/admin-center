AI-Generated Page Quality Rubric

A shared evaluation framework for assessing whether AI-generated web pages meet production quality. Based on analytic rubric design principles (Allen & Tanner, 2006) with criteria applicable to any website regardless of CMS, framework, or design system.

Scope: AI-generated web pages Version: 1.0 Date: 2026-07-03 Dimensions: 5 Criteria: 18

Scoring Levels

Each criterion is scored on a four-point scale. Each level assumes all conditions of the level below are also met.

4 — Excellent

Exceeds expectations. Strengthens the brand and could serve as a reference example for future pages.

3 — Good

Ready to publish. Matches the quality of existing hand-crafted pages on the same site.

2 — Fair

Functional with minor issues. Usable after light editorial or design review.

1 — Poor

Requires significant rework. Structural, visual, or content issues that block publication.

Quality Rubric

18 criteria grouped into 5 dimensions. Weights reflect relative importance to overall page quality. A page must meet the pass threshold defined below to be considered "good quality."

Dimension Criterion 4 — Excellent 3 — Good 2 — Fair 1 — Poor
1. Visual / Layout Correctness 30%
Key indicators Matches existing pages exactly; pristine visual quality Consistent spacing, proper alignment, clear hierarchy Slight spacing inconsistencies, acceptable visual flow Elements overlap, inconsistent margins, broken grids
Visual & Layout Spatial consistency
  • Spacing matches the site's existing pages exactly
  • Vertical rhythm is indistinguishable from hand-built content
  • Spacing follows a consistent scale throughout (e.g., 4/8/16/24/32px or the site's design tokens)
  • Consistent vertical rhythm between sections
  • No misalignment between sibling elements
  • Spacing is mostly consistent; 1–2 irregular gaps
  • Minor inconsistency in section margins
  • Arbitrary, inconsistent spacing throughout
  • Overlapping or clipped elements
Responsive behavior
  • Layout is fluid and polished at every viewport width, not just breakpoints
  • Touch targets meet 44×44px minimum on mobile
  • Layout reflows cleanly from desktop to mobile
  • Images and media scale proportionally
  • No horizontal scroll at any viewport width
  • Desktop renders correctly; mobile has minor overflow or tight spacing
  • Breakpoints exist but some elements don't resize well
  • Fixed-width layout that breaks on smaller screens
  • Content overflows or is inaccessible on mobile
Visual parity
  • Pixel-perfect match to the site's design standards
  • Could be used as a reference example for future pages
  • Visually indistinguishable from existing hand-built pages on the same site
  • Follows established hero, card, grid, and section patterns
  • Recognizably belongs to the site but with minor inconsistencies (border radius, shadow depth, font weight)
  • Looks like a generic template unrelated to the site
  • Mixes visual styles foreign to the site's design language
Color & theming
  • Color usage enhances the page's visual storytelling and brand perception
  • Dark mode (if applicable) is polished, not just functional
  • All colors from the site's defined palette or design tokens
  • Contrast meets WCAG AA (4.5:1 for text, 3:1 for large text)
  • Dark mode renders correctly if the site supports it
  • Mostly on-palette; 1–2 off-brand colors
  • Contrast generally acceptable; one near-miss element
  • Colors unrelated to the site's palette
  • Text-on-background contrast failures
2. Component Composition 25%
Key indicators Innovative yet compliant component arrangements that enhance UX Components follow design system guidelines consistently Components work but could be better organized Wrong components for content type, accessibility violations
Component Composition Design system usage
  • Component choices are optimal — the best variant for each context, not just a correct one
  • Creative use of existing components to solve novel layout needs
  • Uses the site's established UI components (buttons, inputs, cards, navigation) rather than ad-hoc markup
  • Component variants applied correctly (e.g., primary vs. secondary buttons in appropriate contexts)
  • Core interactive elements use site components; 1–2 instances of custom markup where a component exists
  • Custom-styled elements that bypass the site's design system
  • Inconsistent button, input, or card styles on the same page
HTML semantics
  • Semantic structure enhances SEO and assistive technology experience beyond compliance
  • Structured data (schema.org) present where applicable
  • Correct semantic elements throughout (<nav>, <main>, <article>, <section>, <header>, <footer>)
  • No <div> soup; structure is meaningful to screen readers and search engines
  • Valid HTML with no parsing errors
  • Most structure is semantic; a few generic <div>s where a semantic element would be better
  • Entirely <div>-based structure with no semantic meaning
  • Invalid or malformed HTML
Image & media handling
  • Images are optimized with modern formats (WebP/AVIF), lazy loading, and responsive srcset
  • Alt text is descriptive and adds context beyond what's visible
  • Images are appropriately sized (not serving oversized originals)
  • All images have meaningful alt text; decorative images use alt=""
  • No broken image links or placeholder URLs
  • Images display correctly but are not optimized for size
  • Alt text present but generic (e.g., "image1.jpg")
  • Broken images, placeholder URLs, or missing media
  • No alt text on content images
Accessibility
  • Exceeds WCAG AA; approaches AAA in key areas (enhanced contrast, clear focus indicators, skip links)
  • Tested with a screen reader and passes without friction
  • All interactive elements have accessible names
  • Keyboard navigable; focus order matches visual order
  • Color contrast meets WCAG AA
  • Form inputs associated with labels; ARIA landmarks correct
  • Most elements accessible; 1–2 missing labels
  • Keyboard navigation works for primary flows
  • Multiple unlabeled controls or non-focusable interactive elements
  • Information conveyed by color alone with no fallback
3. Structural Consistency 15%
Key indicators Structure enhances content impact beyond the template's baseline All sections present, logical flow, template faithfully followed Mostly complete; minor ordering or proportion issues Missing critical sections, placeholder text, broken structure
Structural Consistency Section completeness
  • All sections present and enhanced with contextually appropriate extras (e.g., social proof, FAQ, related content)
  • All expected sections present (hero, feature highlights, social proof, CTA)
  • Section order follows a logical narrative flow
  • No empty, stub, or placeholder sections
  • Required sections present; order slightly rearranged but still logical
  • One optional section missing or underdeveloped
  • Missing critical sections (e.g., no CTA, no introductory content)
  • Placeholder text like "Lorem ipsum" or "[Insert headline]"
Template fidelity
  • Template structure followed and thoughtfully adapted to the specific content
  • Output matches the selected template in layout structure
  • Grid columns, content zones, and media placements align with the spec
  • Content types match template slots
  • Overall shape matches; minor deviations in grid or proportions
  • Output bears little resemblance to the selected template
  • Completely different layout structure than requested
Information hierarchy
  • Hierarchy guides the reader through a clear narrative arc with natural transitions between sections
  • Clear heading levels (H1 → H2 → H3) with no skipped levels
  • Visual weight matches importance: primary CTA is prominent, secondary actions are subtle
  • Content flows logically top-to-bottom
  • Heading hierarchy present but one level skipped
  • CTA visible but not obviously the primary action
  • No heading hierarchy; all text at similar visual weight
  • Primary CTA buried or competing with multiple equal-weight actions
4. Content Relevance 15%
Key indicators Content exceeds expectations and adds clear value beyond the brief Content serves intended purpose effectively Mostly relevant with minor misaligned sections Content doesn't match page purpose or user needs
Content Relevance Topical accuracy
  • Content demonstrates domain expertise; adds insight beyond what was prompted
  • No generic AI filler — every sentence is specific and purposeful
  • All copy is on-topic and specific to the subject matter
  • No hallucinated facts, fabricated statistics, or non-existent features
  • Claims are plausible and internally consistent
  • Mostly on-topic; 1–2 vague or generic sentences
  • Fabricated details or factually incorrect statements
  • Generic filler unrelated to the intended topic
Content depth
  • Content is rich enough to stand alone without additional editing
  • Includes supporting evidence, examples, or social proof beyond the brief
  • Body sections contain substantive detail, not just headlines
  • Feature descriptions include benefit statements and supporting context
  • Content length appropriate for the page type
  • Content is present but thin; some sections read like outlines
  • Headline-only content with no supporting detail
  • Significantly under expected content length
Channel appropriateness
  • Content is optimized for the channel (SEO-tuned for web, hook-driven for social, CTA-focused for email)
  • Metadata (title tag, meta description, Open Graph) is compelling, not just present
  • Tone, length, and format match the target channel and page type
  • Metadata present and correct
  • Broadly appropriate but some channel conventions missed
  • Content clearly written for a different channel
  • Missing essential metadata
Localization readiness
  • Content is structured for easy translation; text-free images, parameterized formats, flexible containers
  • No text baked into images or hardcoded into layouts
  • Date/number/currency formats are locale-appropriate or parameterized
  • Text containers accommodate 130–150% expansion for translations
  • Most content is translatable; a few labels hardcoded in images or tight containers
  • Significant text baked into images
  • Rigid layouts that break with translated strings
5. Brand Alignment 15%
Key indicators Strengthens brand identity through excellent execution Follows brand guidelines consistently Minor brand guideline deviations Wrong tone, off-brand colors/fonts, messaging conflicts
Brand Alignment Tone & voice
  • Voice is so consistent it enhances brand perception — reads as if written by the brand's best copywriter
  • Tone adapts naturally to the content (e.g., empathetic for support pages, energetic for product launches)
  • Copy reflects the brand's defined tone attributes
  • Voice is consistent throughout the page
  • Follows documented guidelines (sentence structure, word choice, person/tense)
  • Tone is broadly on-brand but inconsistent between sections
  • Occasional phrasing that doesn't match the brand's style
  • Tone contradicts brand guidelines
  • Generic AI-sounding copy with no distinct brand personality
Visual brand
  • Visual execution elevates the brand — color, typography, and imagery work together to create a cohesive, premium feel
  • Colors drawn from the brand palette (primary, secondary, accent applied correctly)
  • Typography matches brand fonts for headings and body
  • Logo/wordmark present in the correct position and size
  • Imagery style consistent with the brand's visual identity
  • Primary brand color correct; secondary or accent slightly off
  • Logo present but placement deviates from guidelines
  • Colors unrelated to brand palette
  • Wrong, missing, or distorted logo; off-brand imagery
Brand guidelines compliance
  • Every brand rule followed and the result enhances the brand's market positioning
  • All explicit brand guideline rules followed
  • Messaging aligns with brand positioning and value proposition
  • Legal requirements met (trademark symbols, disclaimers, copyright)
  • Guidelines mostly followed; one non-critical rule missed
  • Brand guidelines ignored or contradicted
  • Missing required legal notices or disclaimers

Pass / Fail Threshold

A generated page is considered "good quality" when all of the following are true:

  • No criterion scores 1 (Poor) — any Poor score is a blocking defect that requires rework before publication.
  • Weighted average ≥ 3.0 — calculated as: ∑(dimension_avg × weight). A page averaging 2.0 (Fair) across all dimensions is functional but not publishable without significant review.
  • Brand prerequisites met — the page's brand profile has colors defined, fonts configured, and tone/voice guidelines documented.
  • Accessibility floor — no WCAG AA contrast failures, all interactive elements keyboard-reachable, all images have alt text.

How to Use This Rubric

Context Method Outcome
Manual review Reviewer scores each of the 18 criteria 1–4 using the descriptors above. Takes 5–10 minutes per page. Scorecard with per-dimension averages and overall weighted score. Pages ≥ 3.0 pass; others get a list of specific criteria to improve.
Automated checks Criteria from dimensions 1–3 (Visual, Markup, Structure) can be partially automated via HTML validators, accessibility scanners (axe, Lighthouse), and design-token linters. Automated gate that flags low-scoring criteria before human review. Reduces manual effort to dimensions 4–5 (Content, Brand).
AI self-evaluation Pass the rubric as context to the AI system. After generation, the AI scores its own output and flags any criterion below 3. Self-improvement loop: the AI re-generates sections that scored below 3, surfacing only passing pages to the human reviewer.
A/B comparison Score both a hand-built page and an AI-generated version of the same content. Compare per-criterion deltas. Identifies which quality dimensions the AI excels at vs. struggles with, informing prompt engineering and template improvements.

Methodology: Analytic rubric design based on Allen & Tanner (2006), "Rubrics: Tools for Making Learning Goals and Evaluation Criteria Explicit for Both Teachers and Learners," CBE—Life Sciences Education, 5(3), 197–203. Criteria derived from web content quality standards, WCAG 2.1 accessibility guidelines, and industry best practices for brand-consistent content production.

Maintenance: Review and update this rubric quarterly or when significant changes are made to brand guidelines, design systems, or content standards. Add new criteria only when an existing dimension cannot capture a recurring quality issue.
