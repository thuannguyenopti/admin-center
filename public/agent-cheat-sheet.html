Multi-Turn Agent Guide

6 steps to build your first conversational agent.

01
Enable Multi-Turn

Toggle Support multi-turn conversation on. Your agent gains memory across the full conversation.

↳ Multi-turn memory is currently only supported in chat, not in workflows.
02
Write Your Prompt Template

The main task instruction for every run. Structure it so the model steps through your task clearly.

  • [[variable]] for dynamic inputs
  • { Instruction } for explicit directives
  • `tool` to reference a specific tool
  • Include example turns pulled from real usage
03
Set the System Prompt

Permanent persona — applies before every turn, invisible to the user.

  • Persona — name, voice, tone
  • Standing rules — constraints that never change
↳ Keep it tight. A focused system prompt beats a long one every time.
04
Dial In Memory Limit

How many turns the agent retains. Start at 10 and increase only if needed.

Low
5–10
Simple tasks, stateless queries and lookups.
Q&A · Calc
Medium
10–20
Multi-step reasoning, 1–2 knowledge bases.
Research
High
20–50
Full history, deep iterative refinement.
Exploration
05
Craft the First Message

What users see when they call your agent with @handle. Set clear expectations upfront.

↳ Your first message is your agent's handshake. Make it feel like a product, not a chatbot.
06
Save, Test & Iterate

Hit Save, run a Test Run, then publish. The best agents compound over time.

  • Watch real conversations in Logs
  • Pull quality examples to refine your prompt
  • Increase memory limit only if reasoning degrades
